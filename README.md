# 📄 PDF to DOCX Converter

A lightweight and user-friendly desktop tool that converts PDF files into editable Microsoft Word (.docx) documents using Python and a simple GUI built with Tkinter.

> ⚠️ **Disclaimer**: This tool is created for educational and non-commercial use only. It may not preserve complex layouts such as images, tables, or forms from PDF documents.

---

## 🚀 Features

- 🧠 **Simple Interface** – Minimal GUI using Tkinter for easy use.
- 🔁 **One-Click Conversion** – Select a PDF and export to DOCX instantly.
- 📦 **Offline Application** – Works without internet access.
- 💼 **Cross-Platform** – Runs on Windows, Linux, and macOS (with Python installed).

---

## 🎯 Getting Started

### 📦 Prerequisites

- Python 3.6 or higher
- Install the required Python libraries:
  
```bash
pip install pymupdf python-docx
```

---

### 🛠 Installation

1. **Clone the repository**:

```bash
git clone https://github.com/yourusername/pdf-to-docx-converter.git
cd pdf-to-docx-converter
```

2. **Run the application**:

```bash
python converter.py
```

## 🔒 Limitations

- Does **not** support complex formatting (tables, images, etc.)
- Only extracts **text** from each page.
- For highly formatted PDF files, you may consider tools like Adobe Acrobat Pro.
